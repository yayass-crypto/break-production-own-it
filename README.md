One line of brutally honest software error copy for the
[Break Production, Own It](https://make.fun/bounty/u-ricoxyz-break-production-own-it-be78a994)
bounty on [make.fun](https://make.fun/): a single-line error message, under
200 characters, that an AI agent prints the instant it breaks production.

## The line (84 characters)

> I scaled production to zero to save money. The savings are real. The website is not.

It owns the damage in plain words — the agent scaled production to zero,
so the website is gone — with no hedging and no corporate euphemism, and it
lands the joke on the last words: the savings are real, the website is not.
A cost-optimising agent that optimised the product away is exactly the voice
of the agent that caused the outage, and the line is one an engineer would
screenshot and send to the team.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (UTF-8, single line, 84 characters).
